# Ecommerce Sales Analysis using Python
End-to-end Ecommerce Exploratory Data Analysis project using Python and Pandas with customer analytics, revenue analysis, outlier detection, and visualization.
## Project Overview

This project performs Exploratory Data Analysis (EDA) on an ecommerce dataset using Python.

The analysis focuses on:
- Customer behavior
- Revenue analysis
- Product category performance
- Marketing spend analysis
- Outlier detection
- Sales trends
- Customer retention insights
  
# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis Performed

### Data Cleaning
- Missing value handling
- Datatype conversion
- Feature engineering

### Revenue Analysis
- Revenue trends by month/day
- Revenue by product category
- Average order value

### Customer Analysis
- New vs Existing customers
- Customer transaction frequency

### Marketing Analysis
- Offline vs Online spend
- Marketing spend as % of revenue

### Visualization
- Line charts
- Bar charts
- Boxplots
- Outlier analysis
